# Code availability wording template

Use this only after the public repository URL resolves and the release licence has been approved:

> The source code, configuration files, split manifests, and evaluation scripts used in this study are available at [GITHUB_URL], release [VERSION], and archived at [DOI_IF_AVAILABLE]. Trained model weights are [included in the release / available from the corresponding author upon reasonable request]. Provider-restricted imagery is not included.

Until those fields are real, keep the manuscript's current “available from the corresponding author upon reasonable request” wording. Do not insert a placeholder or non-resolving URL into the submitted paper.
